建物A

一質点系では、減衰係数を c = 2hωm とみなして応答を計算します。

k1・c1 は地盤と1質点目の間、k2・c2 は1質点目と2質点目の間です。多質点系では各層の c から減衰行列 C を直接作るため、減衰定数 h は使用しません。
フレームの模式表示は、c=0.5では筋交いなし、c=1.0で片筋交い、c=1.5でX型筋交い、c=2.0以上で制振ダンパーが加わります（実際の部材設計を表すものではありません）。

1値なら全層共通。複数なら質点数と同じ個数。

θᵢ=(xᵢ−xᵢ₋₁)/Hᵢ。青：目安の50%未満、橙：50%以上、赤：100%以上。設定限界に達した層から崩壊演出を開始します。学習用の演出であり、部材の破壊・崩壊後の運動を解析したものではありません。グラフは崩壊後も未損傷の線形モデルの参考応答です。
